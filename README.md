# 과학적 관리법 자율 문항 출제 에이전트 시스템

이 프로젝트는 강의 노트(PDF/TXT)를 분석하여 자율적으로 문제은행을 구축하고, 최종 학생용 문제지 및 교수용 해설지를 `.docx` 워드 파일로 생성하는 **Multi-Agent 오케스트레이션 시스템**입니다.

---

## 1단계. 실행 전 구글 드라이브 & 파일 준비

코드를 돌리기 전에 구글 드라이브에 에이전트가 읽을 강의 자료를 먼저 세팅해야 합니다. 아래 순서대로 똑같이 준비해 주세요.

1. 구글 드라이브 접속: 본인의 Google Drive에 접속합니다.
2. 폴더 생성: 내 드라이브 최상단(루트 디렉토리)에 `scimgmt_hw2`라는 이름으로 새 폴더를 만듭니다. #스펠링 주의!
   * 올바른 경로 예시: `내 드라이브 > scimgmt_hw2`
3. 강의 자료 업로드: 방금 만든 `scimgmt_hw2` 폴더 안에 시험 출제에 사용할 강의 자료 파일(`.pdf` 또는 `.txt`)들을 전부 업로드합니다.
   * 참고 : 시스템이 폴더 내의 모든 PDF와 TXT 파일을 자동으로 인식하여 하나의 거대한 지식 베이스로 병합합니다.

1. 본 저장소에 업로드된 `scimng_HW2.ipynb` 파일을 클릭한 뒤, 상단의 `Open in Colab` 버튼을 눌러 코랩 환경으로 진입합니다.
2. 필수 라이브러리 설치: 코드 맨 위에 있는 라이브러리 설치 셀을 실행합니다. 장소에 포함된 `requirements.txt` 기반으로 안전하게 일괄 설치합니다.
   ```bash
   !pip install google-genai pypdf python-docx requests wikipedia-api
3. 구글 드라이브 연동: drive.mount('/content/drive') 코드가 있는 셀을 실행합니다.
"이 노트북이 Google Drive 파일에 액세스하도록 허용하시겠습니까?"라는 구글 팝업창이 뜨면 Google Drive에 연결을 클릭하고 계정 로그인을 완료해 줍니다.

## 3단계. GCP 프로젝트 ID 및 Vertex AI 인증
이 시스템은 Google Cloud Platform(GCP)의 무료 크레딧($300)을 활용하여 Vertex AI 경로로 Gemini 모델을 호출하므로 개인 프로젝트 ID 인증이 필수입니다.

1. 인증 실행: 코드 상단의 auth.authenticate_user() 셀을 실행하여 구글 계정 로그인 팝업 절차를 완료합니다.

2. 프로젝트 ID 입력: Google Cloud Console에 접속하여 발급받은 실제 프로젝트 ID를 복사합니다.

3. 코드 내 변수에 내 프로젝트 ID를 붙여넣어 문자열을 교체해 줍니다:
   PROJECT_ID = "scimanagementhw2"라고 세팅되어 있는 셀을 찾고, 이 셀을 찾아서 본인 ID로 바꿔주세요.
   PROJECT_ID = "본인의_GCP_프로젝트_ID_입력"


## 4단계. 파이프라인 가동 및 결과물 확인
모든 세팅이 끝났다면 상단 메뉴에서 런타임 -> 모두 실행 (Ctrl + F9)을 누르거나, 아래 공정을 순서대로 가동합니다.

1. bank draft(원안지) 생성
  강의 소스 데이터를 병합하여 2배수 문제은행 초안을 만들고 AI가 자율 검토(Reflection)를 수행합니다.
  완료되면 컴퓨터 왼쪽 파일 탭에 HW2_Scientific_Management_Bank_Draft.docx 워드 파일이 생성됩니다.

2. 최종 시험지 선별 및 추출
   인간 검수자가 원하는 문항 번호(예: 1, 2, 4...)를 선택하고 배점 기준을 입력한 뒤 최종 셀을 실행합니다.
   가동이 끝나면 학생용 시험지(_Questions.docx)와 교수용 해설지(_Answers.docx)가 완벽하게 분리되어 독립된 파일로 자동 산출됩니다.

## **자주 발생하는 오류 및 해결법**
ModuleNotFoundError: No module named 'pypdf'

 라이브러리 설치 셀을 다시 실행해 주세요.

KeyboardInterrupt 또는 타임아웃
:API 호출량이 일시에 몰려 멈추는 경우, 당황하지 마시고 코랩 상단 메뉴의 런타임 -> 세션 다시 시작을 누른 뒤 위에서부터 셀을 하나씩 다시 실행해 주시면 정상 작동합니다.
